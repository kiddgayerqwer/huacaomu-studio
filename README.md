# 花草沐studio 客戶管理

給健身教練與芳療按摩師使用的客戶管理網頁，主要在 iPad 上使用。

## 功能
- 會員資料（含健康狀況、精油過敏提醒）
- 買課紀錄與剩餘堂數自動扣抵、到期提醒、未付款提醒
- 健身上課紀錄（訓練重點、動作／重量／次數／組數、回家功課）
- 芳療服務紀錄（精油、調油配方、部位、力道、前後狀況、居家建議）
- 合約建檔與 iPad 手寫簽名，可列印或存成 PDF
- 預約行事曆（完成後一鍵轉成上課／服務紀錄）
- 身體數據與趨勢圖
- 營收統計、匯出 Excel (CSV)、完整備份與還原
- 離線使用：沒網路也能新增修改，連網後自動上傳

## 資料存放
1. **iPad 本機**：所有資料先存在 iPad（IndexedDB），離線可用。
2. **Google 雲端**：透過 Google Apps Script 存到你自己的 Google 試算表。
3. **gym 資料夾**：雲端程式每 5 分鐘把有變動的會員輸出成 PDF（會員紀錄、合約）到 Google 雲端硬碟的 `gym` 資料夾，電腦安裝「Google 雲端硬碟」後會自動同步下來。

## 設定 Google 雲端（只需做一次）
1. 打開 https://script.google.com ，按「新專案」，專案名稱改成「花草沐studio 雲端」。
2. 把 `google-apps-script/Code.gs` 的內容全部貼上，取代原本的程式，按儲存。
3. 上方函式選單選 `setup`，按「執行」，依畫面允許權限（會出現「Google 尚未驗證」，按「進階」→「前往」）。
4. 下方「執行記錄」會顯示 **通行碼**，記下來。
5. 右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」，執行身分「我」，存取權「所有人」→ 部署，複製 **網頁應用程式網址**。
6. 在 iPad 打開網站 →「設定」→ 貼上網址和通行碼 →「連線並開始同步」。

## 安裝到 iPad
用 Safari 開網站 → 分享 →「加入主畫面」。
